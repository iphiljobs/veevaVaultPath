# Veeva Vault Platform Engineering Guide

A free, practical learning guide for the Veeva Vault Platform. The companion site brings together Veeva primary sources, a dependency-based study path, implementation labs, and production-readiness guidance.

## Published guide

**[Open the live Veeva Vault Platform Engineering Guide](https://iphiljobs.github.io/veevaVaultPath/)**

Jump directly to a section:

- [Free resource directory](https://iphiljobs.github.io/veevaVaultPath/#resources) — Veeva Developer Portal and Help, API/VQL/MDL/Java SDK docs, Direct Data API, Postman, Toolbox, public Veeva code, community, and compliance resources.
- [Sequential learning path](https://iphiljobs.github.io/veevaVaultPath/#path) — ten stages, from platform basics and security through VQL, integrations, Java SDK customization, testing, and validation.
- [Suggested documentation structure](https://iphiljobs.github.io/veevaVaultPath/#structure) — a MkDocs-friendly file tree for expanding the standalone guide into a larger curriculum.
- [Practical code labs](https://iphiljobs.github.io/veevaVaultPath/#labs) — a parent/child VQL extraction example and a Java SDK before-trigger validation example.
- [Production readiness checklist](https://iphiljobs.github.io/veevaVaultPath/#release) — requirements, security, testing, evidence, change control, deployment, and operations review points.

## What the guide covers

- Free-to-read public documentation and resources maintained by Veeva or its developer community.
- Core Vault concepts: administration, users and permissions, object/document configuration, lifecycles, workflows, and audit trails.
- VQL and MDL, API authentication and versioning, Postman, Toolbox, integration design, and release-aware SDK setup.
- Java SDK record triggers and validation patterns, with reminders to verify API signatures, schema names, and release compatibility against current official documentation.
- Risk-based testing and validation practices for controlled production changes.

## Run or deploy

The published site is a self-contained `index.html` with embedded CSS and JavaScript. Open [index.html](https://github.com/iphiljobs/veevaVaultPath/blob/main/index.html) in a browser for a local preview; no package installation or build step is required.

GitHub Pages is configured to deploy from **`main` / `/(root)`**. The live site is available at [iphiljobs.github.io/veevaVaultPath](https://iphiljobs.github.io/veevaVaultPath/).
