# Veeva Vault Platform Engineering Guide

A free learning guide for building practical Veeva Vault Platform skills. The site covers primary public resources, a dependency-based curriculum, VQL relationship extraction, a Java SDK record trigger example, and validation readiness.

## Open the site locally

Open [index.html](index.html) in a browser. The page is self-contained and has no build dependencies.

## Publish with GitHub Pages

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.

The site uses static HTML, CSS, and JavaScript. No package install or build step is required.

## Learning content

- Official Veeva developer and help documentation, plus free tooling and public community/compliance references
- Sequential study path from Vault administration and security through VQL, APIs, Java SDK, and validation
- Repository layout guidance for a maintainable learning resource
- Practical VQL and Java SDK examples with implementation notes

This is an independent educational guide. Confirm platform behavior, SDK signatures, and release-specific requirements in current Veeva documentation before using examples in a Vault.
